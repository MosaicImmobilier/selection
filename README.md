# Sélections MOSAIC

Page vue par les clients de MOSAIC Immobilier d'entreprise quand leur conseiller leur envoie une sélection de biens.
Elle ne contient aucune donnée : elle lit la sélection du client dans la base, par le code secret de son lien, pendant 15 jours.
La source est dans le dépôt du logiciel (dossier `selection/`).
